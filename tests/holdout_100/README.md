# KarriereKrake HOLDOUT 100

100 vollständig synthetische Lebensläufe für einen ungesehenen Akzeptanz-/Regressionstest. Keine echten Personen oder Kontaktdaten.

## Inhalt
- `cvs/`: 100 PDFs
- `expected_results_full.json`: vollständige Ground Truth pro Dokument
- `solution_sheet.csv`: kompaktes, menschenlesbares Lösungsblatt

## Regeln
1. Diesen Satz nicht zum Entwickeln einzelner Parserregeln verwenden.
2. Keine Dateinamen, Namen, Arbeitgeber oder Werte hardcoden.
3. Erst nach eingefrorener Implementierung auswerten.
4. Fehlende Angaben bleiben leer; keine Halluzinationen.
5. Ergebnisse pro Feld und pro Kategorie messen.

Die Fälle variieren Beruf, Person, Anschrift, Grenzregion, Bildungsweg, Berufsstationen, Layout, Sprache, fehlende Felder, C1-Kontext, überlappende Zeiträume und absichtlich unsichere Daten.
